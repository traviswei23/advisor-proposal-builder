# 当方案的关键难点仍未讲清

## 用机制模式生成真正可比较的备选

只选能改变当前预测的一两种。套用外部模式前核对该文真正操作过的步骤、成立条件和失败例。写“借用的结构｜本问题中的对应量｜必须更改的操作｜会失败的边界”，把没有证据支撑的环节列作候选假设。

| 瓶颈 | 可采用的机制操作 | 对照或反例 |
| --- | --- | --- |
| 条件变化使同一个操作失效 | 让策略显式依赖可测条件，或编码已有结构约束 | 比较不分条件的朴素方案，测条件量不可得时发生什么 |
| 整体路线由多种不同过程组成 | 拆分任务、按不同机制处理，再交接可检验的中间量 | 比较统一处理与打乱分配的结果；核算新增复杂度 |
| 两种方法看似互斥 | 在共同表示中推导是否等价，再寻找它们分开的条件 | 换符号和尺度后是否还是同一运算？哪种反例给不同结果？ |
| 可得到的监督信号有限 | 用构造的、可核对的替代信号检验目标；检查测量或生成过程 | 保留简单独立参照，排查信号泄漏、混杂与循环定义 |
| 离散空间难于计算 | 研究连续松弛、近似可解对象或可分解的子问题 | 恢复离散解时是否仍可行？构造近似失效的小型例子 |
| 只能看到失败，无法说清上限 | 先给出系统边界或限制的可复核描述，再尝试越过其中一个限制 | 原条件和新条件分开报告；排除额外信息或更大预算带来的好处 |
| 方案说靠多个组件互补 | 先写每个接口传递的量、时刻和用途，再提出有方向的互作预测 | 去掉或扰动接口、匹配参数与资源；检查剩余结果是否仍同样可解释 |

参考技术工作时，先写来源对应的原理，再写自己的解释；引用位置与操作链分开检查。例题能帮助形成假设，但不能代替本方案证据。改公式、方法、输入条件后，重新检查依赖它的推导、实验对照和中心图。能构造数值或理论例时，先做量纲、退化、符号、信息可得性和输入—输出自洽检查。确实执行过的检查和建议执行的检查分别登记。

## 导师选路线时可以追问的三个层次

1. **若完全做成，值不值得？** 说明对当前解释、测量能力或研究者决策的增量。列同样资源下最强的替代研究方向。若现方案仅改善次要指标，说明何种用户或研究问题真会受益。
2. **是否做得成且能判别成功？** 确认设备/数据、学习成本、可用周数、关键合作和评估先例。写一个来自公认先例的可比基准。对照不可得则收窄主张；证据只够做描述时先交付测量可行性。
3. **在替代路线面前还选它吗？** 提出者和质疑者各写最强论证；记录谁因哪条事实改了判断，并按科学价值、可信度、近期投入分开推荐。把“未来可能成立的理想方案”与“本周最值得做的工作”区分开。

问题范式可能真的改变、或关键技术将进入不同成熟阶段时，再从基本物理或数学约束重新推导，用反事实问“去掉这个惯用假设，问题是否仍以原形式存在？”不要因听起来像范式转移就提高证据等级。

## 复核材料和工作进度

编号每个待定或已确认的科学目标、独立实验单位、证据和未决前提。资料复杂时，为关键设计保留“要证明哪一条｜原始证据位置｜哪些结论依赖此证据｜改动后要重做哪些检查”。每一个阶段结束写可核的退出条件；建好文件、提交代码、程序运行成功和科学主张获得支持是不同判据。冲突数据、非预期结果和失败记录留在案。

若需要正式预登记，固定预测方向、主要分析、剔除标准、缺失数据处理、偏离预案的记录和独立复验条件。不同研究设计有不同偏差来源；考察测量盲法、选择性报告、统计功效、重复单位和公共数据重叠时逐项说明为何适用。探索性工作只固定它确实能承诺的部分。
